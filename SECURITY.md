# Security Policy

## Supported versions

This repository is maintained on the `main` branch. Security fixes are applied there; historical tags and releases are provided as-is.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Use GitHub's private reporting flow:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Include the affected version or commit, reproduction steps, and impact.

If private reporting is unavailable, contact the maintainer through the email listed on the GitHub profile.

## Scope

This policy covers the code and configuration in this repository. Third-party dependencies and vendored code remain under their own upstream policies.
