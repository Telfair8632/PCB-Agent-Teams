# 布线策略 — KRT 配方的逐网判断框架

`route` 工具把 A* 寻路做成机械执行;**线宽多少、哪些网走粗、差分对怎么处理、布线顺序选哪个**是电路判断,由 AI 按本文先给 net 分类再定配方。跟 draw-pcb 总分工一致:判断走回路,机械走脚本。

> 反模式:把 `route` 当裸 `route <pcb>` 一键跑,近 70 个 KRT 参数全吃默认。默认 track width 很细(~0.1mm),对电源配电干线偏窄;差分对不设阻抗就当普通网布。

## 先分类,再定配方

布线前对板上的网做一次分类——这一步必须有可见输出(打印每类有哪些网):

| net 类 | 怎么认 | 配方 |
|---|---|---|
| **信号网** | 一对一 / 少 pad,小电流 | `--track-width` base 值;通常吃 KRT 默认即可 |
| **电源网** | 配电干线 / 多 pad 供电网 / 已知较大电流 | 进 `--power-nets`,`--power-nets-widths` 给加宽线 |
| **差分对** | 名字成对(`*_P`/`*_N`)、需阻抗匹配(如 ADC / 高速) | `--impedance` 设目标阻抗;P/N 尽量同层并行 |
| **GND** | 地回流网 | **照常布,别排除**。`route` 已经把 Phase D 的铜剥掉了(见 `routing.md`「为什么先剥铜」),此刻板上没铜,GND 必须靠走线 + via 连通。**❌ 禁止用 `--nets` 把 GND 排除出布线**——那样 GND 只剩事后重铺的 zone,铜一旦被走线切碎就是孤岛,正是剥铜要消灭的失效模式 |

**不需要配方就别配**:一块全是小信号、无电源干线、无差分对的简单板,裸 `route <pcb>` 吃默认就对——不要为了用参数而用。配方是给"有功率网 / 有差分对 / 布不通"的板。

## 各轴判断

### 线宽(--track-width / --power-nets-widths)
- 信号网:base 宽度够载流即可,默认偏细但短走线无妨。
- 电源网:线宽由**电流**定,不是拍脑袋。方向性参考 IPC-2221 外层经验(约 0.5mm/A @ 10℃ 温升),但实际取值还要看 fab 最小线宽能力和走线长度(IR 压降)。把判断写出来,别套死表。
- 同一块板信号网和电源网线宽**应当不同**——一刀切是反模式。

### 电源网识别(--power-nets)
**直接用 `placement_brief` 的 `power_nets`**(结构判据:被 ≥2 个电容旁路到地 = 送电网,
不靠名字),别自己按网名猜。`power_net_why` 给了每条的判定依据,不认同再人工增删。
配电干线(一个网喂多颗 IC / 多个 pad)、已知大电流支路,都该进 `--power-nets`。KRT 原生支持给指定网单独走粗线,这是它的核心能力,别漏用。

> 名字有误导:`--power-nets` 收的是**任意网名 pattern**,不限电源。任何"这几个网要走
> 别的宽度"的需求都用它 + `--power-nets-widths` 配对表达(差分对要求 ≥ 某宽度也走这条)。
> 它只在**布线那一刻**生效——线已经布完再想改宽,不是这个参数的事,得重布。

### 差分对(--impedance / --length-match-group)
名字成对、功能上需要阻抗匹配的网(ADC 差分输入、高速串行等)用 `--impedance` 设目标阻抗。

**等长是能做的**,别推给 GUI:`--length-match-group P N` 让 KRT 给短的那根加蛇形补长,
`--length-match-tolerance` 给容差,`--meander-amplitude` 给蛇形幅度。实测一对 RS485:
不设等长 delta = 0.69mm;`--length-match-group` + `--length-match-tolerance 0.05
--meander-amplitude 0.5` 后 delta = 0.076mm。

⚠️ **蛇形塞不进去时会静默不动**:同一对网只给 `--length-match-group`(幅度吃默认 1.0mm)
时 delta 仍是 0.69mm——通道装不下 1.0mm 幅度,一根蛇形都没加,**工具不报错**。
规则:窄通道把 `--meander-amplitude` 调小(0.3~0.5mm),**并且每次都用 `net_metrics.py
--pairs "P,N"` 量 delta**。「我传了等长参数」不是等长的证据,量出来的 delta 才是。

### 布线顺序(--ordering)
- `inside_out`(KRT 默认):多数板适用,从板内向外布。
- `mps`:拥挤板 / 默认顺序布不通时试。
- `original`:复布场景,保持原网表顺序。
布不通时,换 ordering 是低成本的第一手,优先于改线宽 / 加层。

`--ordering` 只有这三种算法,**没有「让某些网先布」的参数**。要指定顺序就分多遍跑:
第一遍 `--nets <关键网>`,后续每遍在**上一遍的产物上**布其余(最后一遍不传 `--nets`)。
KRT 会跳过已布通的网,先布的走线原样保留——实测一对 RS485 第一遍布完
(delta 0.69 / via 2·0),第二遍又布了 67 个网,该对的长度与过孔数**一字不差**。

⚠️ **第一遍的反噬:stub 预留**。KRT 布线时给**全板所有未布网**的 stub 周围加绕行代价
(日志 `Found N unrouted nets in PCB for stub proximity`)。`--nets` 只选少数网时,
没被选中的网也全在预留——**板越空、抢网越少,第一遍越容易被自己邻居的预留堵死**,
症状是关键网在自己焊盘出口处就失败,而同板全网一次布反而通。对策按序:
①第一遍多带几个同区域的网一起布(减少"旁观网");②调小 `--stub-proximity-radius`
(默认 2.0mm)——但调小后走线可能贴着邻近焊盘/过孔走,布通后**必须**用 `run_drc` +
`net_metrics` 回验净距,别拿"布通了"当"合法了"。

**多遍编排的优先级判据**(每遍布谁,按约束刚性排,不是随意的):
1. **带硬约束的网先布**(过孔上限 / 长度上限 / 等长对)——晚了通道被无约束网占掉,
   约束必然超标;
2. **跨板长网先布**(两端距离接近板对角线量级的网)——它要横穿整板,越晚可用走廊越少;
3. **密集双排连接器,电源/宽线排先于信号排**——宽线要的通道大,信号先占了它就挤不进;
4. **差分对两根同一遍一起布**——拆开布,先到的把后到的逼去绕远路,长度差直接失控。
判据全部来自约束刚性:**谁的自由度少谁先走**。每遍布完看 `failed` 与 `net_metrics`,
失败的网挪到更早一遍重试,而不是加大所有遍的力度。

### via 尺寸与过孔预算(--via-size / --via-drill / --via-cost / --layer-costs)
尺寸:默认通常够用。仅在大电流过孔需要加粗、或 fab 钻孔能力有下限时才调。

**数量**靠代价压,不是靠上限——KRT 没有「每网最多几个过孔」这种硬参数,只有换层代价:
- `--via-cost N`:每个过孔的 A* 惩罚(默认 50,单位=栅格步长)。调高 → 换层变贵 → 宁可绕远。
- `--via-proximity-cost`:细间距 / stub 邻近区的过孔倍率(0 = 该区禁打过孔)。
- `--layer-costs`:按层的代价乘子,与 `--layers` 位置配对。两层板想让底层多留给地平面就调高它。

⚠️ **这是代价不是上限,而且要拿布通率换**:实测同一块板全网布线,`--via-cost 50 → 400`
过孔数 192 → 109(−43%),但布通 69 → 38、失败 6 → 9。**过孔预算和布通率是同一个方向盘的两头**,
调完必须用 `net_metrics.py --max-vias N` 量真实过孔数 + 看 `failed`,别只调参数不看代价。

## 与其它阶段的衔接
- 布线**必须先过 route-ready 验收**(见 SKILL.md)——烂布局上布线 = 烂地基盖楼。
- 布完线**必须重铺 GND 铜**——见 `references/copper_pour.md`。`route` 布线前把铜剥掉了,
  **不重铺板上就没有铜**,不是"铜变旧了"而是"铜没了"。
- 布完**必跑 `run_drc`**——KRT 自报布通不等于 DRC 干净;`copper_edge_clearance` 等违例的处理见 `routing.md`。
